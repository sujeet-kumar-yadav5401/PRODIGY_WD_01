# Responsive Landing Page — Internship Task 01

## Task Requirements
- Fixed navigation menu visible on all pages/sections.
- Navigation changes style after scrolling.
- Menu items have hover effects.
- HTML used for structure.
- CSS used for responsive styling.
- JavaScript used for scroll and navigation interaction.
- Responsive on desktop, tablet and mobile.

## Files
- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — scrolling, active menu and mobile menu

## Run Locally
1. Open the project folder in VS Code.
2. Open `index.html`.
3. Right-click the file and choose **Open with Live Server** if the Live Server extension is installed.
4. Otherwise, double-click `index.html` to open it in a browser.
